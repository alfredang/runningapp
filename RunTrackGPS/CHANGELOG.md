# Changelog

## [1.9] - 2026-10-06

- Fixes voice coaching going silent when Google Maps is used alongside a run (and staying silent after it is closed).
- The run map can now be panned and zoomed freely; tap the location button to follow again.
- Choosing a destination now shows the planned route and its distance straight away, even before a run.
- New: Back to Start — one tap plans the shortest route back to where the run began.
- New: live distance from your Start point on the run screen.
- New: trophies next to your fastest-pace and longest-distance runs in Run History.

## [1.8] - 2026-09-12

- Restores reliable voice coaching for distance, pace, kilometre, and goal announcements while music or video is playing.
